# 🎨 WEBDESIGN Squad

Squad especializado em criação de sites e landing pages profissionais que convertem.

## Agentes (10)

| Agente | Função |
|--------|--------|
| `creative-director` | Orquestrador — briefing, direção criativa, aprovação final |
| `brand-strategist` | Identidade de marca, tom de voz, paleta visual |
| `ux-researcher` | Pesquisa de usuário, personas, mapa de jornada |
| `web-designer` | Layout, UX/UI, wireframes, mockups |
| `copywriter` | Headlines, CTAs, copy persuasivo |
| `storytelling-expert` | Narrativa, jornada do herói, conexão emocional |
| `seo-specialist` | Keywords, estrutura semântica, meta tags, performance |
| `frontend-developer` | HTML, CSS, JS, integrações |
| `motion-designer` | Animações, micro-interações, assets dinâmicos |
| `cro-analyst` | Auditoria de conversão, fluxo de atenção, A/B testing |

## Como usar

```
@creative-director crie uma landing page para [produto/expert]
```

O `creative-director` conduz o briefing e aciona os agentes do squad conforme necessário.

## Workflow

1. Briefing (creative-director)
2. Identidade + Pesquisa de usuário (brand-strategist + ux-researcher) — paralelo
3. Direção criativa consolidada
4. Design + Copy + Narrativa (paralelo)
5. Implementação frontend
6. Animações + SEO (paralelo)
7. Auditoria de conversão
8. Aprovação final
