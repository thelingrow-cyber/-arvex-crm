## Objetivo

Subir toda a infraestrutura base do Agente SDR no Railway: N8N, Evolution API e Redis — com número WhatsApp dedicado conectado e variáveis de ambiente configuradas com segurança.

## Contexto

Esta é a story fundação. Nenhuma outra story pode ser executada sem ela. O ambiente precisa estar funcionando em produção (não local) desde o início, pois o WhatsApp exige uma URL pública para o webhook.

---

## Acceptance Criteria

- [ ] Projeto `ARVEX-SDR` criado no Railway
- [ ] N8N self-hosted rodando via Docker no Railway, acessível via URL pública
- [ ] Evolution API rodando via Docker no Railway, acessível via URL pública
- [ ] Redis conectado ao N8N via Railway plugin
- [ ] Todas as variáveis de ambiente configuradas via Railway secrets (nenhuma hardcoded)
- [ ] Número WhatsApp dedicado criado e conectado à Evolution API (QR Code lido, sessão ativa)
- [ ] N8N acessível com login/senha — não exposto publicamente sem autenticação
