## Objetivo

Transformar o canal de comunicação em um agente inteligente: integrar Claude API com system prompt da Carol, implementar memória de conversa via Redis e aplicar a lógica de qualificação/desqualificação para o nicho Cindy Batista (dono de ótica).

## Contexto

Esta é a story central do agente. A Carol precisa: manter contexto entre mensagens do mesmo lead, qualificar pelo critério correto (ótica própria em operação), desqualificar com gentileza e escalar para Gabriel quando necessário.

## Acceptance Criteria

- [ ] Claude API integrado no fluxo N8N — cada mensagem do lead é processada pelo Claude
- [ ] System prompt da Carol implementado com todas as seções definidas

- [ ] Agente desqualifica com gentileza lead que não é dono de ótica

## System Prompt — Estrutura

```
[PERSONA]
Nome: Carol
Missão: Identificar donos de ótica que podem se beneficiar do método da Cindy Batista
Tom: Próximo, prático, profissional — nunca robótico

[CONTEXTO]
Expert: Cindy Batista — especialista em gestão e vendas para óticas
Produtos: Mentoria R$5k | Assessoria R$7k | Consultoria presencial R$10k

[QUALIFICAÇÃO]
Critério: Dono(a) de ótica com loja ativa
Desqualificado: Funcionário, sem loja própria, ideia sem operação

[FLUXO]
1. Saudação personalizada
2. Entender contexto do lead (ótica, tamanho, desafio)
3. Qualificar com perguntas naturais
4. Se qualificado: apresentar brevemente + propor call
5. Agendar call com closer

[ESCALADA]
- Lead faz pergunta técnica fora do escopo
- Lead demonstra irritação
- 3 mensagens sem avanço na qualificação
- Lead pede para falar com humano

[PROIBIÇÕES]
- Nunca prometer resultados específicos
- Nunca revelar preço antes de qualificar
- Nunca pressionar ou usar urgência falsa
```
