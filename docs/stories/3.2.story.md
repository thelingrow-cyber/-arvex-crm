## Objetivo

Criar o canal de comunicação bidirecional entre WhatsApp e N8N: receber mensagens (texto e áudio), transcrever áudio via Whisper e enviar respostas — sem lógica de negócio ainda, apenas o canal funcionando.

## Contexto

Esta story estabelece o "tubo" de comunicação. O N8N precisa receber cada mensagem do lead, processar e responder. Áudio é crítico pois leads frequentemente enviam mensagens de voz no WhatsApp.

---

## Acceptance Criteria

- [ ] Webhook Evolution API → N8N configurado e recebendo eventos
- [ ] N8N processa mensagens de texto e extrai: número do remetente, texto, timestamp
- [ ] N8N processa mensagens de áudio: faz download do arquivo e transcreve via Whisper API
- [ ] N8N envia mensagem de texto de volta ao lead via Evolution API
- [ ] Teste ponta-a-ponta: enviar texto → N8N recebe → N8N responde → WhatsApp exibe resposta
- [ ] Teste ponta-a-ponta: enviar áudio → N8N transcreve → N8N responde com transcrição confirmada
- [ ] Logs de erro configurados para falhas de webhook
