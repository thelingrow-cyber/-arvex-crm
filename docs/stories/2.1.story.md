**Epic:** EPIC-2 — Plataforma CRM ARVEX
**Status:** InProgress

## Objetivo

Construir o MVP do CRM Comercial ARVEX — uma estrutura visual para apresentar aos sócios o que está nascendo na operação comercial. Roda no navegador (HTML puro + LocalStorage), sem necessidade de servidor ou deploy.

## Contexto

A operação comercial hoje roda informalmente no WhatsApp. Este MVP organiza visualmente o fluxo de leads, indicadores e pipeline para dar estrutura ao que já existe e apresentar aos parceiros (Dr. Alex, Cindy Batista).

---

## Acceptance Criteria

- [ ] Dashboard com 6 cards de indicadores (Novos, Interações, Ligações, Vídeo, Calls, Agendamentos)
- [ ] Pipeline Kanban com colunas SDR + Closer
- [ ] Formulário de cadastro de novo lead
- [ ] Dados persistem via LocalStorage
- [ ] Layout responsivo, visual profissional (paleta ARVEX)
- [ ] Funciona offline, abre como arquivo HTML no navegador

---

## Pipeline — Colunas

### Fase SDR
1. **Novo** — Lead entrou
2. **Contato** — SDR fez primeiro contato
3. **Qualificado** — Lead qualificado, pronto pro Closer

### Fase Closer
4. **Call** — Call com o Closer realizada
5. **Follow Up** — Aguardando decisão do lead
6. **Fechado** ✅ — Venda fechada
7. **Perdido** ❌ — Não converteu

---

## Campos do Lead

- Nome completo
- Telefone (WhatsApp)
- Expert vinculado (Dr. Alex / Cindy Batista / Outro)
- Origem (WhatsApp / Instagram / Indicação / Tráfego Pago)
- Responsável (SDR / Closer)
- Observações
- Data de entrada
- Histórico de atividades (interações registradas)
