# Fontes — construção da marca pessoal

Transcrições e materiais que o Vitor manda para lapidar a marca. Uma pasta só, um arquivo por fonte.

## Fluxo

1. **Entra:** o Vitor cola a transcrição no chat → vira `AAAA-MM-DD-autor-tema.md` aqui, com o texto bruto.
2. **Destila:** no fim do arquivo, a seção `## O que tirar daqui` (até 5 pontos, cada um com o trecho que sustenta).
3. **Aplica:** o que for aprovado sobe para a página única da marca (`MARCA-PESSOAL.md`, a criar), citando a fonte.

Regras: material de mentoria de terceiro não é fonte (ver `squads/conteudo/squad.yaml → fontes_proibidas`);
modelar é diferente de transpor, então expressões e frases dos autores não vão para roteiro.
