# Roteiro — "O melhor dentista da cidade"

**Status:** final, aprovado para gravar · 2026-09-23
**Duração:** ~45s · **Função:** alcance · **Sem CTA**
**Família de gancho:** arquétipo inesperado + pergunta com alvo
**Dor:** `d-cabeca` — "roda na minha cabeça" · **ICP:** profissional liberal (beachhead vigente)

## Roteiro

```
Você já percebeu que o melhor dentista da cidade
quase nunca tem a maior clínica?

Não é falta de vontade não.
É que quando você é o melhor, cai tudo em você.

O caso difícil, a reclamação,
o cliente antigo que só volta se for com você.

Aí você não consegue passar pra ninguém,
porque ninguém faz igual.
E é verdade. Ninguém faz igual mesmo.

Só que isso tem nome, sabe.
Tem um livro de 95 que chama isso de suposição fatal.
Que é quando você acha que, porque é bom no que faz,
você sabe tocar o negócio.

Não é a mesma coisa.
Uma você estudou anos pra aprender.
A outra ninguém nunca te ensinou.

E hoje isso tá acontecendo de novo, com outra roupa.

O cara aprendeu a usar IA. Usa todo dia, ajuda pra caramba.
Aí ele acha que botou IA no negócio dele.

Não botou não. Ele tá usando. É outra coisa.

Porque nos dois casos é igual:
você sabe fazer.
Só que continua sendo você que faz.

E enquanto depender de você, cara,
não é negócio. É você com hora marcada.
```

## Notas de gravação

- **Take único, sem corte.** A peça é conversa, não montagem. Os maiores alcances do banco são take único.
- **A pausa que importa** é depois de *"E é verdade. Ninguém faz igual mesmo."* — é onde o espectador se reconhece.
- **Card na tela:** só "suposição fatal · livro de 1995" quando você falar o nome. Nada mais.
- **Corte opcional** se quiser ~35s: tirar *"Não é a mesma coisa. Uma você estudou anos pra aprender. A outra ninguém nunca te ensinou."* O vídeo se sustenta sem.

## Checagem de fonte

- *Suposição Fatal* (Fatal Assumption) é termo nomeado por Michael Gerber em **The E-Myth Revisited (1995)**
  — verificado em `.claude/clones/michael-gerber/` com fontes indexadas.
- O roteiro **não afirma o que o livro diz** além do nome do conceito. Livro e ano são fato.
- O paralelo com IA é **do Vitor**, não do Gerber. Ele nunca escreveu sobre IA.
- Nenhum número citado. Nenhuma promessa de faturamento.

## Histórico das correções (para calibrar os próximos)

1. **"pior clínica" → "quase nunca tem a maior".** "Pior" faz o ouvinte entender *trabalho ruim*, o que é
   falso — o melhor dentista faz o melhor trabalho. O que trava é o negócio, não a qualidade.
2. **"a clínica é ruim porque ele é bom" caiu.** Ser excelente no ofício não *causa* má gestão; não
   existe esse mecanismo. O que existe é concentração: tudo rota pra ele, ele vira o gargalo.
3. **"não é apesar dele ser bom não" caiu.** Frase elíptica — depende de uma oração que nunca foi dita.
   No papel dá pra montar; na boca, passa batido.
4. **O paralelo com IA foi do meio para o fim.** No meio, exigia dois conceitos de uma vez e virava
   isca e troca. No fim, cai em terreno já preparado e o espectador faz a ligação sozinho.
5. **Linguagem.** Saíram os paralelismos simétricos e as frases completas demais; entraram as
   respirações reais dos takes dele — "não ... não", "sabe", "cara", "E é verdade."
