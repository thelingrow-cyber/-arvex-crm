# Roteiro — "Você não é livre" (Platão, 15s)

**Status:** v1 · 2026-10-08 · **Molde:** 🪞 CONFRONTO · **Função:** alcance · **Duração:** ~15s · **Sem CTA**
**Base:** tradução/adaptação de referência sobre a *República* (o homem democrático do Livro VIII), feita no chat de 08/10
**Texto fixo na tela:** *você não é livre*

## Roteiro

```
Você diz que é livre porque não tem chefe.

Mas acorda e pega o celular. Come o que dá vontade. Responde com raiva.

Isso não é liberdade.
É obedecer.

Livre de verdade é quem consegue dizer não pra si mesmo.
```

## Notas de gravação
- *"Isso não é liberdade."*: pausa depois.
- *"É obedecer."*: seco, olhando na lente.
- O fecho é mais lento.

## Variante com autoridade (~17s, molde FRASE)
```
Platão já avisava: o mais fácil de controlar é quem acha que fazer tudo o que quer é ser livre.
Você não tem chefe. Mas o seu impulso tem.
Livre de verdade é quem consegue dizer não pra si mesmo.
```
"Já avisava", nunca "disse": é paráfrase da *República*, não citação literal.
