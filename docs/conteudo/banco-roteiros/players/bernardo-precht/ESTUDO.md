## Como é o vídeo das 8h (notícia)

1. **Abertura com a notícia já em leitura**, não o fato seco: "Só 2,2% das famílias nos EUA pagam assinatura de IA",
   "A notícia mais bizarra desse ano", "Começou com o videogame, depois o Spotify, depois o Photoshop".
2. **Explica o mecanismo em linguagem de leigo** ("todo programa tem um código, ele é compilado em 0 e 1…").
3. **Leva para negócio:** "e quando a gente leva isso para negócio, esse gráfico do Pat Grady explica uma das maiores
   oportunidades…".
4. **Ressalva honesta:** "E óbvio que eu estou exagerando aqui. Tem muita coisa que você não vai extrair… Só que tem muita
   coisa que você vai."
5. **Fecho de opinião, falado:** "Mas o fato é, tudo mudando muito, muito rápido." / "E eu falo com alguma propriedade
   desse assunto."
6. Duração: mediana de 98s, entre 60 e 180s. Legenda curta, tom de conversa ("Fiquei de cara", "Essa é a nova febre").

## O que não levar

- O lugar dele ("direto do Vale do Silício", "aqui em Stanford"). O equivalente honesto do Vitor é "eu li inteiro" ou "eu
  testei construindo".
- Vídeos de 3 minutos: para o Vitor, de 45 a 90s.
- Citação famosa no fecho (proibida para o Vitor).
