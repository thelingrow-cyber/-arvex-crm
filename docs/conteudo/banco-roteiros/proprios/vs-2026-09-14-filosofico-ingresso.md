# Dinheiro não é o destino. É o ingresso.

## Roteiro

```
"Dinheiro não é o destino. É o ingresso."
A maioria trabalha a vida inteira pra comprar coisa. Carro, casa, relógio. E acha que chegou.
Isso é o jogo pequeno.
O jogo real é o que você constrói com o que ganhou. O que continua funcionando quando você não está na sala.
Porque audiência que não virou ativo é só número. E conhecimento que não virou sistema é só informação.
Você não está construindo patrimônio. Você está construindo um emprego caro que você mesmo criou.
```
