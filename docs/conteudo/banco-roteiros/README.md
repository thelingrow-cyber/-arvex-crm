# 🎬 Banco de Roteiros

> Roteiros de referência (terceiros) e próprios, dissecados na mesma ficha, para descobrir **o que
> estrutura um roteiro que funciona** — não para colecionar texto.
> **Obedece:** [`../../ecossistema/brand-book-marca-pessoal.md`](../../ecossistema/brand-book-marca-pessoal.md) ·
> famílias de gancho G1–G10 em [`../../ecossistema/sistema-de-roteiro.md`](../../ecossistema/sistema-de-roteiro.md)

---

## As três regras

1. **Referência nunca ganha "deu certo".** Ela diz *o que testar*, não *o que funciona para você*.
2. **Roteiro próprio só ganha "deu certo" com número**, medido no 7º dia. Sensação não conta.
3. **Toda ficha termina em esqueleto reutilizável.** Análise que não vira molde é admiração.

## Estrutura

```
banco-roteiros/
  README.md          este arquivo — regras e molde
  _molde.md          ficha em branco
  referencias/       terceiros  →  ref-{autor}-{slug}.md
  proprios/          seus       →  vs-{AAAA-MM-DD}-{slug}.md
```

## O que cada ficha responde

| Seção | Pergunta |
|---|---|
| **Cabeçalho** | o que é, de quem, qual programa/faixa, gancho, funil, métricas, veredito |
| **Transcrição** | o texto literal, com tempo |
| **Arquitetura** | quais fases, em que segundo, com que função |
| **Mecânicas** | o que *faz* funcionar — cada uma nomeada, para virar vocabulário do banco |
| **O que não copiar** | o que colide com o brand book |
| **Esqueleto** | o molde abstrato, reaproveitável em qualquer tema |
| **Adaptação** | como isso vira um roteiro seu |

## Vocabulário de mecânicas

*Cresce a cada ficha. Nomear a mecânica é o que permite perguntar ao banco "isso funciona?".*

| Mecânica | O que é | Vista em |
|---|---|---|
| **Loop aberto** | promete no início uma resposta que só vem no fim | ref-luana-conselho-dos-ricos |
| **Segredo revelado** | o narrador quebra um pacto de silêncio em favor de quem assiste | ref-luana-conselho-dos-ricos |

| **Emoção positiva → perigo** | virtude reconhecida é reenquadrada como armadilha | ref-luana-conselho-dos-ricos |
| **Ruptura de registro** | quebra abrupta de tom ("meu bem, acorda") no pico da tensão | ref-luana-conselho-dos-ricos |
| **Fato + como agir** | informar não influencia; influencia quem diz o que fazer com o fato | ref-luana-informante-influenciador |

## Candidato a nova família de gancho

**G11 · Segredo guardado** — *"o que [grupo com poder] faz e não conta"*. Não existe em G1–G10.
⚠️ Só serve ao Arquiteto se o "grupo" for **quem já opera** (empresas que rodam com IA), nunca
"os ricos" nem **quem vendeu IA ao cliente** — atacar o fornecedor dele é chamá-lo de otário
(brand book §02.3). Promover a G11 só depois de um teste próprio com número.
