# O Messi não foi para a Copa para jogar futebol

## Por que é "normal" (2k — o mais fraco do lote)
- **O gancho é bom no papel** ("não foi para jogar futebol e quase ninguém percebeu") — mas o corpo é **estatística de km percorrido**
- **Curiosidade sem ameaça**: nada no vídeo afeta a vida do espectador; o Messi andar mais é admirável, não perturbador
- A lição (jogar como xadrez, fazer menos e decidir melhor) é **consenso de produtividade**
- Tem a **melhor prova própria** do lote (esposa: 0 → 753 mil em 137 posts) e mesmo assim não performou — prova não compensa gancho fraco

**Achado:** notícia do momento não basta. **Virginia na Globo (55,7k)** também era Copa — mas tinha dinheiro, celebridade e *"deveria te incomodar"*.
