## Visão Geral

A ARVEX opera com 3 formatos de lançamento intercalados conforme estratégia do mês.

| Formato | Duração total | Objetivo principal |
|---------|--------------|-------------------|
| **Webinário Semanal** | 7 dias | Geração de leads para o comercial |
| **Lançamento Mensal Pago** | 15 dias | Venda direta via grupo pago (meteórico) |
| **Lançamento Clássico Interno** | ~10-12 dias | Conversão de base interna (3 dias de vendas) |

---

## FORMATO 1 — Webinário Semanal

```
Dia 1-6: Captação de leads (anúncios)
        ↓
Dia 7: Live do webinário (Zoom/Meet)
        ↓
Pós-live: Mensagens no grupo → Sessão estratégica → Closer
```

### Etapas

| Dia | Atividade | Responsável | Ferramenta |
|-----|-----------|------------|-----------|
| D-7 a D-1 | Subida e otimização de anúncios | Gestor de tráfego | Meta Ads |
| D-7 a D-1 | Captação de leads na página | — | Página de vendas + Kiwify |
| D-7 a D-1 | Entrada de leads no grupo WhatsApp | SDR / Gabriel | WhatsApp |
| D-7 a D-1 | Aquecimento do grupo (mensagens) | Vitor / Gabriel | WhatsApp |
| D-7 | Live do webinário | Expert (Cindy/Alex) + Vitor | Zoom / Meet |
| Pós-live | Live de dúvidas / novo conteúdo | Expert + Vitor | Zoom / Meet |
| Pós-live | Mensagens nos grupos → Sessão Estratégica | Gabriel + Vitor | WhatsApp |
| Pós-live | Calls de vendas com leads aquecidos | Closer | Zoom / Meet |

## FORMATO 2 — Lançamento Mensal Pago (Meteórico)

```
Dia 1-14: Captação para grupo pago (ingresso)
        ↓
Dentro do grupo: Sequência meteórica (conteúdo + oferta)
        ↓
Dia 10-12: Venda de ingressos via página normal
        ↓
Dia 13-15: 2-3 dias de vendas diretas
```

### Etapas

| Fase | Atividade | Responsável | Ferramenta |
|------|-----------|------------|-----------|
| Captação (D-15 a D-7) | Anúncios para grupo pago | Gestor de tráfego | Meta Ads |
| Captação | Página de venda de ingresso | Web designer | Kiwify |
| Meteórico | Sequência de conteúdo no grupo | Vitor (copy) + Expert | WhatsApp |
| Vendas (D-10 a D-12) | Página de vendas principal ativa | Web designer | Kiwify |
| Vendas | Disparos nos grupos (avisos) | Gabriel / Vitor | WhatsApp + LeadLovers |
| Vendas | SMS e chamadas para leads | — | LeadLovers |
| Fechamento | Follow-up e calls de vendas | Closer | Zoom / Meet |

## FORMATO 3 — Lançamento Clássico Interno (3 dias)

```
Dia 1-10: Captação para base interna
        ↓
Dia 11-13: 3 dias de vendas intensivas (lives + mensagens)
        ↓
Pós: Sessões estratégicas com não-compradores
```

### Etapas

| Fase | Atividade | Responsável | Ferramenta |
|------|-----------|------------|-----------|
| Captação | Anúncios + aquecimento da base | Gestor + Vitor | Meta Ads + WhatsApp |
| CPL (conteúdo) | Lives de conteúdo pré-lançamento | Expert + Vitor | Zoom / Meet |
| Abertura | Pitch de abertura de carrinho | Vitor (copy) + Expert | Zoom / Meet |
| Vendas (3 dias) | Disparos de mensagens | Gabriel / Vitor | WhatsApp + LeadLovers |
| Vendas | Página de vendas ativa | Web designer | Kiwify |
| Fechamento | Lives de dúvidas / fechamento | Expert + Vitor | Zoom / Meet |

## Checklist Universal de Lançamento

### PRÉ-LANÇAMENTO (15 dias antes)
- [ ] Definir formato e data do lançamento
- [ ] Briefar gestor de tráfego (objetivo, público, verba)
- [ ] Web designer cria/atualiza página de vendas
- [ ] Configurar checkout no Kiwify
- [ ] Criar grupo WhatsApp do lançamento
- [ ] Escrever copy dos anúncios (Vitor)
- [ ] Escrever sequência de mensagens do grupo (Vitor)
- [ ] Preparar roteiro da live com expert (Vitor + Expert)
- [ ] Treinar expert para a live

### DURANTE O LANÇAMENTO
- [ ] Anúncios no ar — acompanhar métricas diariamente
- [ ] Disparar mensagens de aquecimento no grupo
- [ ] Confirmar presença do expert na live
- [ ] Realizar live (Vitor presente do início ao fim)
- [ ] Disparar avisos no LeadLovers (SMS + chamadas) no dia da live
- [ ] Monitorar grupo e responder dúvidas

### PÓS-LANÇAMENTO
- [ ] Live de dúvidas / conteúdo adicional
- [ ] Extrair números do grupo para follow-up
- [ ] Disparar mensagens para leads não convertidos → Sessão Estratégica
- [ ] Passar leads qualificados para o closer
- [ ] Onboarding dos novos alunos (Sabrina)
