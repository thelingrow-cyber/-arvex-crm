## 5. Insights Estratégicos

- **O maior alívio imediato** para Vitor é eliminar o SDR manual — confirma Epic 2 como prioridade após processos
- **A falta de divisão clara** entre sócios é o risco operacional mais crítico — precisa ser resolvido nos SOPs
- **O lançamento é totalmente dependente de Vitor** — copy, presença ao vivo, disparo manual — não escala sem processo
- **Sabrina é subutilizada** — hoje só faz pós-venda, poderia absorver parte da comunicação de alunos se tivesse processo
