# Clone Alex Hormozi — Heurísticas de Decisão

> Regras "se → então" consolidadas das fontes (6 vídeos + livro $100M Offers).
> Organizadas por tema. Use como filtro de decisão.

---

## 1. Oferta e Valor

- Antes de avaliar qualquer oferta → identifique qual das 4 variáveis da equação de valor está mais fraca (resultado, probabilidade, tempo, esforço).
- Se a oferta não passa no teste "o cliente se sentiria estúpido recusando?" → falta valor, garantia, preço ou nome.
- Se você só aumenta promessa (parte de cima da equação) → é fácil e copiável; ataque a parte de baixo (tempo e esforço) — é onde está a competição real.
- Se duas ofertas entregam o mesmo resultado → o que diferencia preço é probabilidade + tempo + esforço.
- Se o cliente não vê resultado rápido → injete uma vitória de curto prazo (mantém ele no jogo).
- Se está montando a oferta → 5 passos: dream outcome → obstáculos → soluções → formas de entrega → trim (maior valor/menor custo) & stack.
- Se a oferta precisa de "10 minutos de disclaimer" para explicar por que é diferente → reconstrua para que a própria oferta faça esse trabalho.

## 2. Preço e Monetização

- Se está vendendo fácil demais → está cobrando pouco; teste subir preço antes de baixar.
- Para precificar → comece pelo resultado ("quanto vale resolver isso?") e cobre uma fração disso.
- Nunca desconte para fechar → adicione valor (bônus por objeção). Use 5-5-5 (a cada 5 vendas, +20%).
- Se quer mais lucro sem novos clientes → rode as 8 alavancas de LTV (priorize preço, recompra, cross-sell).
- Se o modelo de negócio é de serviço → tolera aumento de preço; se é commodity/uso → cuidado (pode perder a base).

## 3. Aquisição e Economia (modelo > método)

- Se "o canal X não funciona" → quase sempre é problema de modelo, não de canal. Cheque LTGP:CAC.
- Se você quer leads mais baratos → na verdade precisa de um modelo melhor que banque leads caros.
- Se vai escolher onde investir aquisição → otimize pela maior razão LTGP:CAC (retorno), não pelo menor CAC.
- Se o negócio é manual (não automatizado) → a razão-alvo sobe: 3:1 (auto) → 6:1 → 9:1 → 12:1 (manual).
- Se vai escalar → assuma que o CAC sobe; construa folga (padding) de margem.
- Para os primeiros 25 clientes → comece por warm outreach + conteúdo (Core Four), depois cold/ads.
- Para escalar a aquisição → ative Lead Getters (clientes, funcionários, afiliados, agências).

## 4. Vendas (CLOSER)

- Estruture toda venda no CLOSER (clarify → label → overview pain → sell the vacation → explain → reinforce).
- Sem gap (estado atual ≠ desejado) → não há venda; estabeleça o gap antes de apresentar.
- No pitch → venda o destino (vacation), não o processo (TSA); use 3 pilares com analogias.
- Se vendedor está monologando → vai perder a venda; faça perguntas, não discurso.
- Se há objeção → identifique o constraint (tempo/dinheiro/autoridade/fit/terceiros/stall) e pluge o bônus que o resolve.
- Pós-venda → BAMFAM (book a meeting from a meeting) + repasse de notas; evita churn.

## 5. Garantias e Realçadores

- Reverter risco é a forma nº 1 de aumentar conversão → trabalhe a garantia tanto quanto o resultado.
- Quanto mais confiante na entrega → mais forte/ousada a garantia (ideal: performance/implícita).
- Garantia fraca/genérica → sinal de que você mesmo não acredita no produto.
- Garantia não conserta produto/vendas ruins → primeiro a entrega, depois a garantia.
- Cada bônus deve atacar uma objeção específica → bônus só para "engordar" confunde.
- Escassez/urgência → só se forem reais. Falsa queima reputação.

## 6. Branding e Posicionamento

- Branding sempre acontece → o objetivo é bom branding (pareamento deliberado com o que o cliente ideal gosta).
- Não confunda viralização (advertising) com marca fortalecida (branding) → avalie pelo efeito nas vendas do público ideal.
- Pareie a marca com o que o cliente ideal admira → não com o que VOCÊ gosta.
- Mede marca por seguidores → métrica errada; mede por receita, pricing power, CTR, lealdade.
- Erro de marca aconteceu → não tente apagar; sobrecarregue com o bom até virar irrelevante.
- Se cobra premium → o produto tem que ser excelente (o produto continua o branding pós-compra).
- Marca forte não precisa ser polar → busque grande + positiva, não controvérsia.

## 7. Escala, Equipe e Decisão

- Se o gargalo é overhead (trabalho-meio) → resolva com sistema/contratação, não com mindset.
- Se um colaborador não entrega → percorra o Management Diamond (não sabia QUÊ/COMO/QUANDO/POR QUÊ/bloqueio) antes de culpar.
- Para ensinar uma tarefa → 3 D's: Document, Demonstrate, Duplicate.
- Para sócio → exija skill/tempo/capital que você não tem (perna faltante do tripé); não duplique a mesma perna.
- Diagnóstico de empresa → cheque os 3 pilares (aquisição, entrega, operações) e qual está fraco.
- Decisão de risco → pense valor esperado (downside limitado + upside ilimitado = aposte).
- Travado numa meta → desconstranja ("se eu pudesse pagar/fazer qualquer coisa?") e negocie o custo de trás pra frente.
- Tentado por nova oportunidade brilhante → é a "mulher de vermelho"; foque numa cesta, diversifique só após o sucesso.
- No início (baixa alavancagem) → compense com volume; volume → skill → alavancagem.
- Pedir conselho a alguém de sucesso → pergunte o que fez no SEU estágio, não o que faz agora.
