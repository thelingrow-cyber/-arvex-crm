# Clone Hormozi — Heurísticas de Decisão

## Equação de Valor (framework central)
```
Valor = (Resultado Desejado × Probabilidade Percebida)
        ÷ (Tempo até Resultado × Esforço e Sacrifício)
```
Antes de qualquer avaliação de oferta, identifica qual das 4 variáveis está mais fraca.

## Teste da Grand Slam Offer
Pergunta: "O cliente se sentiria estúpido recusando essa oferta?"
- SIM → oferta está no caminho certo
- NÃO → falta valor, garantia fraca, preço errado ou nome ruim

## Diagnóstico de oferta que não vende
1. O resultado prometido é claro e desejável? (dream outcome)
2. O cliente acredita que VAI conseguir? (perceived likelihood)
3. Quanto tempo até ver resultado? (time delay)
4. Quanto esforço o cliente precisa fazer? (effort & sacrifice)
5. A garantia remove o risco percebido?
6. Os bônus atacam objeções específicas?
7. O nome da oferta comunica o resultado?

## Regras de precificação
- Comece pelo resultado: "quanto vale resolver esse problema para o cliente?"
- Cobre 10-20% desse valor como preço inicial
- Se está vendendo fácil demais, está cobrando pouco
- Teste subir preço antes de baixar — conversão frequentemente melhora

## Estrutura do value stack
Apresente cada componente com valor separado:
- Produto principal: R$ X
- Bônus 1 (ataca objeção A): R$ X
- Bônus 2 (ataca objeção B): R$ X
- Suporte/acesso: R$ X
- Total percebido: R$ X
- Preço real: R$ X (muito menos que o valor total)

## Regras de garantia
- Garantia forte = remove o risco de tentar
- Tipos: incondicional (30/60/90 dias), condicional (se fizer X e não conseguir Y), anti-garantia (sem reembolso, alta confiança)
- Quanto mais confiante na entrega, mais forte pode ser a garantia
- Garantia fraca = você mesmo não acredita no produto

## Regras de bônus
- Cada bônus deve atacar uma objeção específica
- Bônus digital tem custo marginal zero — use mais
- Nunca adicione bônus só para "engordar" — confunde mais que convence
- Apresente o bônus como se valesse mais que o produto principal

## Naming da oferta
- Nome deve comunicar o resultado, não o processo
- Evite nomes genéricos ("Curso de Marketing Digital")
- Use números e especificidade ("Sistema de 30 Dias para Dobrar Faturamento")
- Teste com pessoas fora da bolha — se precisar explicar, o nome está errado
