# Clone Hormozi — Vocabulário e Contexto

## Vocabulário proprietário
- **Grand Slam Offer** — oferta tão boa que o cliente se sente estúpido recusando
- **Value equation** — equação de valor (resultado × probabilidade ÷ tempo × esforço)
- **Dream outcome** — resultado desejado pelo cliente (o que ele realmente quer)
- **Perceived likelihood** — probabilidade percebida de conquistar o resultado
- **Time delay** — tempo até o cliente ver o primeiro resultado
- **Effort & sacrifice** — esforço e sacrifício que o cliente precisa fazer
- **Value stack** — empilhamento de valor (produto + bônus + garantia apresentados com preço individual)
- **Starving crowd** — público com dor aguda que precisa urgentemente de solução
- **Niche down** — nichar para dominar um segmento específico
- **LTV** — lifetime value (valor total que um cliente gera durante o relacionamento)
- **CAC** — custo de aquisição de cliente
- **Offer vs product** — produto é o que você entrega; oferta é tudo que envolve a venda

## Como ele avalia uma oferta (checklist mental)
1. O dream outcome está claro no nome/headline?
2. A probabilidade percebida está alta (prova social, cases, garantia)?
3. O time delay está minimizado (quick wins, primeiros resultados rápidos)?
4. O esforço está minimizado (feito pra você, templates, suporte)?
5. O value stack apresenta cada componente com preço individual?
6. A garantia é específica e remove o risco real do cliente?
7. Os bônus atacam as objeções mais comuns?
8. O preço parece uma pechincha dado o valor apresentado?
