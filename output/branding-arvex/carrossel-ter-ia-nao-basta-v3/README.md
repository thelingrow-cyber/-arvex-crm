# ARVEX — Ter IA não basta · direção v3

Revisão do carrossel de sete páginas, 1080 × 1350 px. O verde da v2 foi esfriado
para um tom de petróleo (`#16383C` / `#0B2529`), com marfim (`#F0EAE0`) e latão
pontual (`#B89B70`). Permanecem o wordmark oficial e o gesto gráfico de linhas
conectadas por pequenos nós quadrados.

## Ritmo

1. Imagem conceitual de maquete + tese.
2. Fotografia conceitual do painel de conexões interrompidas + tensão.
3. Diagnóstico tipográfico em quatro quadrantes.
4. Maquete anotada + papéis de pessoas, sistemas e IA. Há um roteiro visual
   para uma versão animada em `video-lamina-04-plano.md`; ela ainda não foi
   renderizada (não substituir o PNG por vídeo inexistente).
5. Fotografia conceitual de mesa de planejamento + comparação antes/depois.
6. Percurso tipográfico de implementação.
7. Fotografia conceitual de uma ponte real entre edifícios + conclusão.

Arquivos: `slides/01.png` a `slides/07.png`, `contact-sheet.png`, `index.html`.
Recriar com `node output/branding-arvex/carrossel-ter-ia-nao-basta-v3/build.cjs`.

As imagens adicionais e seus prompts estão em `assets/`. Nenhuma imagem é
evidência de case ou cliente; não publicar como prova de resultado. O sistema
visual e a fonte ainda aguardam aprovação do Vitor.
