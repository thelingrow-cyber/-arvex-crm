# ARVEX — identidade institucional v1

Primeira proposta visual para o rebrand do perfil `@arvexcompany`.

## Conceito

**Arquitetura ao redor de um núcleo.** O “A” é construído por vigas geométricas. O
quadrado dourado marca o núcleo operacional. No wordmark, o mesmo núcleo aparece no
cruzamento do “X”, conectando símbolo e assinatura.

## Uso

- Instagram: `arvex-avatar-light.png` (recomendado) ou `arvex-avatar-dark.png`.
- Fundos claros: `arvex-wordmark-light.svg`.
- Fundos escuros: `arvex-wordmark-dark.svg`.
- Avaliação: `arvex-brand-board.png`.

Os SVGs são os arquivos mestres. Os PNGs são exportações de conveniência em alta
resolução. Esta proposta ainda depende de aprovação visual e não inclui verificação de
disponibilidade marcária.

## Paleta

- Carvão: `#0B0D10`
- Marfim: `#F2F0EA`
- Dourado: `#C8A96E`
